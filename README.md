<h3 align="left">🌟 Projetos em destaque</h3>

<h4><a href="https://github.com/LuisLopesDEV/Mostra-de-Profissoes-2026-CCO">Mostra de Profissões 2026 — Visão computacional</a></h4>

<p>
Projeto do <b>Centro Acadêmico de Ciência da Computação (CACCO)</b> para a
<b>IV Mostra de Profissões da UNIFEI, campus Itabira</b>.
Trabalhei no desenvolvimento de <b>Corte no Ar</b> e <b>Polígonos 3D</b>, duas das cinco experiências do estande.
Todas rodam no navegador e aceitam gestos pela webcam ou controles com o mouse.
</p>

<h5>Funcionalidades</h5>
<ul>
  <li><b>Corte no Ar</b> — corte frutas com o indicador ou com a palma e dispute um lugar no ranking local.</li>
  <li><b>Polígonos 3D</b> — use o gesto de pinça para arrastar vértices e deformar sólidos.</li>
  <li><b>Sistema Solar</b> — explore os planetas e suas órbitas em uma cena 3D.</li>
  <li><b>Voo do Gaguinho</b> — mova a mão para guiar o personagem entre os dutos.</li>
  <li><b>Tiro ao Alvo</b> — mire com a palma aberta e feche a mão para disparar.</li>
</ul>

<h5>Conceitos aplicados</h5>
<p>
O <b>MediaPipe Hand Landmarker</b> rastreia 21 pontos por mão, e o código em <b>TypeScript</b> usa essas posições para interpretar os gestos. No Corte no Ar, o jogo verifica se o trajeto da lâmina entre dois quadros cruza uma fruta.
O projeto usa <b>Canvas 2D</b> nos jogos e <b>Three.js</b> no Sistema Solar. O <b>Vite</b> compila a versão do estande, que roda offline com um servidor local em <b>Node.js</b>.
</p>

<h4><a href="https://github.com/LuisLopesDEV/user-management-api">User Management API (FastAPI + JWT)</a></h4>

<p>
API REST em <b>FastAPI</b> para autenticação e gerenciamento de usuários e pedidos.
Desenvolvi o projeto para simular um trabalho de freela com regras de acesso por perfil e por dono do recurso.
</p>

<h5>Funcionalidades</h5>
<ul>
  <li>Login via <b>JWT</b> e hash de senhas com <b>bcrypt</b></li>
  <li>Controle de acesso por perfil (<b>user</b> e <b>admin</b>)</li>
  <li>CRUD de usuários e pedidos com validação de permissões</li>
  <li>Logout com invalidação de token</li>
</ul>

<h5>Conceitos aplicados</h5>
<p>
Controle de acesso baseado em papéis (RBAC), validação de dados com Pydantic, SQLAlchemy ORM,
códigos de status HTTP e separação de responsabilidades.
</p>

<h4><a href="https://github.com/LuisLopesDEV/Login-withMySQL">Sistema de Login com Python e MySQL</a></h4>

<p>
Sistema de autenticação em <b>Python e MySQL</b> com cadastro de usuários, hash de senhas e controle de sessão.
</p>

<h5>Funcionalidades</h5>
<ul>

  <li>Hash de senhas com <b>bcrypt</b></li>
  <li>Controle de sessões e cookies</li>
  <li>Logout com encerramento da sessão</li>

<h5>Conceitos aplicados</h5>
